# تقرير فحص مشروع «دليلك» — النسخة 2.0

> فحص كامل للباك إند والويب (بدون قسم الموبايل)، مع إصلاح كل المشاكل وإعادة بناء الواجهة بتصميم جديد.
> النسخة القديمة محفوظة كاملة في `_old_v1/` وفي الأرشيف `_backup_v1.tgz`.

---

## 1) شو كان منجز بالنسخة القديمة

| القسم | الحالة |
|---|---|
| الباك إند | هيكل جيد (Entities / Repositories / Services / Controllers / Routes)، JWT + Refresh، Roles، Swagger، Redis، Cloudinary، Rate limit — **بيشتغل لكن فيه ثغرات وأخطاء مهمة** (تحت) |
| قاعدة البيانات | 17 جدول تقريباً تغطي الفكرة الأساسية |
| الويب | هيكل صفحات موجود لكن **أغلب الصفحات شكلية**: ساعات الدوام مكتوبة يدوياً، الخريطة ثابتة على الرياض، البحث بيبعت `query` بدل `q`، التقييم بيبعت `comment` بدل `content`، البلاغ بيبعت `reason` بدل `type`، رفع الصور باسم حقل غلط… يعني الواجهة فعلياً ما كانت مربوطة صح مع الـ API |

## 2) الأخطاء والثغرات اللي انصلحت (الباك إند)

### أمنية (خطيرة)
1. **Mass-assignment**: صاحب النشاط كان فيه يبعت `status: "approved"` أو `isFeatured: true` أو `averageRating: 5` بطلب التعديل ويتنفذ! نفس الشي بالتقييمات (`likesCount`, `isHidden`) والبلاغات. ← الآن كل endpoint بياخد **فقط** الحقول المصرّح فيها بالـ validation (`matchedData`).
2. **تسريب بيانات شخصية**: صفحة النشاط والتقييمات كانت ترجّع إيميل ورقم موبايل صاحب النشاط والمعلّقين لأي زائر. ← serializers عامة آمنة.
3. Refresh tokens كانت تتخزن نص صريح بقاعدة البيانات ← صارت **SHA-256 hash** + rotation + كشف إعادة الاستخدام (يلغي كل الجلسات).
4. أسرار JWT الافتراضية كانت تشتغل بالإنتاج ← السيرفر يرفض الإقلاع بالإنتاج بدون أسرار قوية.
5. رسالة الدخول كانت تفرّق بين "الإيميل غلط" و"كلمة السر غلط" (user enumeration) ← رسالة موحدة.

### أخطاء وظيفية
6. **البحث كان رح يضرب Error 500**: `MATCH ... AGAINST` بدون FULLTEXT index، والترتيب `sortBy=rating` على عمود غير موجود. ← محرك بحث جديد يدعم العربي.
7. **الـ slug بيمحي الحروف العربية** (أي اسم عربي ← slug فاضي/تعارض). ← slugify يدعم Unicode.
8. **ما في طريق لمستخدم عادي يضيف نشاطه** (إنشاء النشاط كان محصور بـ business_owner، وما في شي يرقّي المستخدم). ← أي مستخدم مسجّل بيضيف نشاطه، وعند الموافقة بيترقى تلقائياً لـ "صاحب نشاط".
9. التمييز المدفوع (Featured) ما كان يأثر على الترتيب أبداً ← الآن المميّز **يطلع أول** بكل القوائم والبحث (أهم نقطة للربح).
10. حذف تصنيف/مدينة فيها أنشطة كان يعطي 500 ← رسالة 409 واضحة.
11. حذف مفضلة/لايك ممكن ينزل العداد تحت الصفر، وعمليات سباق بالـ like ← عمليات ذرّية.
12. `normalizeEmail` كان يشيل النقاط من Gmail (fadi.ali@gmail ← fadiali@gmail) ← معطّل.
13. Swagger ما كان يشتغل بعد `npm run build` (مسار src) ← التوثيق صار يتولّد من الراوتات نفسها: **105 endpoint موثّقة تلقائياً**.
14. رفع الصور ما بيشتغل بدون Cloudinary ← تخزين محلي تلقائي `/uploads` إذا Cloudinary مو مضبوط.
15. أخطاء Multer / JSON / Duplicate كانت ترجع 500 ← رسائل صحيحة 400/409/422.
16. Rate limit عام 200 طلب/15 دقيقة (قليل جداً لتطبيق تصفح) ← 1500 قابل للضبط من `.env`.
17. أعمدة `string | null` بالكيانات كانت رح تفشل بـ TypeORM (`DataType Object`) ← أنواع صريحة.
18. `KEYS` بـ Redis (بيوقف السيرفر مع داتا كبيرة) ← `SCAN`.
19. AuditLog موجود بس ما حدا عم يستخدمه ← مفعّل على كل عمليات الإدارة، مع إخفاء كلمات السر.
20. `forgot/reset password` موجودة بالواجهة بس ما إلها API ← منفّذة (SMTP اختياري، وبوضع التطوير بيرجع الرابط).

## 3) الإضافات الجديدة (الباك إند)

- **بحث عربي ذكي**: توحيد الحروف (أ/إ/آ←ا، ة←ه، ى←ي، حذف التشكيل وأل التعريف) + **مرادفات لكل تصنيف** يحطها الأدمن (مثلاً «طبيب عيون» بيلاقي «طب العيون» و«عيادة» و«نظارات»)، ترتيب حسب الصلة، ويشتغل على MySQL و MariaDB.
- **فلاتر**: التصنيف/الفرعي/المدينة/الحي/التقييم/السعر/**مفتوح الآن**/موثّق/مع صور/**بالقرب مني** (Haversine) + 7 أنواع ترتيب.
- **حساب "مفتوح الآن"** حسب توقيت سوريا مع دعم الدوام الليلي (18:00 → 02:00) و24 ساعة.
- **Endpoint واحد للرئيسية** `/home`: تصنيفات + مدن + سلايدر إعلانات + مميّزين + الأعلى تقييماً + الأحدث + إحصائيات (ممتاز للموبايل: طلب واحد).
- **اقتراح نشاط** من مستخدم ما بيملكه + **طلب ملكية (Claim)** لنشاط ضافه الأدمن يدوياً ← عند الموافقة بيصير المالك.
- **نظام ربح كامل**: إعلانات حسب المكان (سلايدر/بانر/نتائج البحث/صفحة التصنيف…) مع استهداف مدينة/تصنيف وعدّاد مشاهدات ونقرات، + باقات تمييز، + **صاحب النشاط بيطلب الإعلان/التمييز من التطبيق** والأدمن بيوافق بعد الدفع.
- **إحصائيات لصاحب النشاط**: مشاهدات، اتصالات، واتساب، اتجاهات، زيارات الموقع، حفظ، توزيع النجوم.
- **إشعارات داخلية** (قبول/رفض نشاط، تقييم جديد، رد على تقييمك، قبول طلب ملكية/ترويج).
- ردود صاحب النشاط على التقييمات، "مفيد" للتقييمات، إبلاغ عن تقييم مزيف، إخفاء التقييم من الأدمن.
- **تحليلات البحث للأدمن**: الأكثر بحثاً + **عمليات بحث بلا نتائج** (يعني شو لازم تضيف داتا!).
- رسائل "تواصل معنا"، إدارة المستخدمين (أدوار/إيقاف)، سجل العمليات.
- حقول إضافية للنشاط: الاسم بالإنجليزي، وصف مختصر، الحي، هاتف ثاني، واتساب، روابط سوشال، مستوى الأسعار، **تفاصيل حرة** (الاختصاص، سنوات الخبرة، رقم النقابة…)، الخدمات (موقف، توصيل، مولدة…).
- **Seed جاهز**: 17 مدينة سورية بالإحداثيات + 17 تصنيف و85 تصنيف فرعي (أطباء بكل الاختصاصات، مطاعم، فنادق، محامين، صيانة وحرفيين، نقل وتحميل، مواد غذائية…) مع المرادفات + حساب أدمن، و`--demo` لبيانات تجريبية.
- `database/schema.sql` جاهز للإنتاج (بدون migrations) + `npm run db:sync`.

## 4) الويب — إعادة بناء كاملة

- تصميم جديد عصري: تدرّج بنفسجي-وردي مع لمسة برتقالية، بطاقات ناعمة، أنيميشن خفيف، **عربي RTL افتراضي + إنجليزي**، **فاتح/داكن**، ومتجاوب بالكامل مع شريط سفلي للموبايل.
- **الضيف** بيتصفح الرئيسية والتصنيفات وتفاصيل أي نشاط والتقييمات، وأي محاولة بحث/تقييم/حفظ/إضافة بتفتح نافذة "سجّل دخولك" وبترجعه لنفس المكان بعد الدخول.
- صفحة النشاط: معرض صور + Lightbox، شعار، شارات (موثّق/مميّز/مفتوح الآن)، أزرار اتصال/واتساب/اتجاهات Google Maps، دوام الأسبوع مع تمييز اليوم، خريطة، تفاصيل وخدمات، تقييمات مع توزيع النجوم وترتيب و"مفيد"، رد المالك، إبلاغ، مشاركة، طلب ملكية، أنشطة مشابهة، وشريط أزرار ثابت على الموبايل.
- بحث: اقتراحات فورية، فلاتر كاملة، عرض **شبكة / قائمة / خريطة**، تمرير لانهائي، الفلاتر بالرابط (قابلة للمشاركة).
- لوحة المستخدم، لوحة صاحب النشاط (محرر نشاط بتبويبات + اختيار الموقع على الخريطة + محرر الدوام + رفع الصور + الأداء + الرد على التقييمات + طلب الترويج)، ولوحة إدارة كاملة (13 شاشة مع رسوم بيانية).
- تم إصلاح مشكلة توافق مع Chrome الحديث كانت رح توقف الصفحات (useEffect يرجع Promise) وترقية react-router لـ v7 المتوافق مع React 19.

## 5) تحسينات مقترحة للمرحلة الجاية (حسب الأولوية)

1. **OTP عبر SMS/واتساب** للتسجيل والتحقق من أصحاب الأنشطة (بسوريا الرقم أهم من الإيميل).
2. **Push notifications** (FCM) للموبايل — جدول الإشعارات جاهز، بس بدها ربط FCM tokens.
3. **صيدليات مناوبة** بجدول مناوبات حسب التاريخ (طلب كتير شائع).
4. **حجز مواعيد** للأطباء/الصالونات (Appointments) — ميزة مدفوعة ممتازة.
5. **عروض وكوبونات** من المحلات (Offers) تظهر بالرئيسية.
6. **صور مع التقييمات** + فلترة الكلمات المسيئة تلقائياً.
7. **باقات اشتراك شهرية لأصحاب الأنشطة** مع دفع إلكتروني (Sham Cash / MTN Cash / Syriatel Cash) بدل الموافقة اليدوية.
8. **Elasticsearch/Meilisearch** لما يصير عدد الأنشطة > 50 ألف (حالياً LIKE + فهرس كافي).
9. **SEO للويب**: Server-side rendering أو pre-render لصفحات الأنشطة (Next.js أو vite-plugin-ssr) + sitemap — مهم ليطلع دليلك بنتائج Google.
10. Google Maps JS بدل OpenStreetMap إذا بدك (بدها API key)، حالياً الخريطة OSM مجانية وزر "الاتجاهات" بيفتح Google Maps.
11. اختبارات آلية (Jest + Supertest) و CI، و Docker compose للتشغيل بأمر واحد.
12. لوحة عربية لتعديل نصوص الصفحات الثابتة (من نحن…) من الأدمن.
